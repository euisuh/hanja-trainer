漢字 Trainer · 시행일 2026년 9월 15일

漢字 Trainer는 한 가정 안에서 함께 쓰는 한자 학습 앱입니다. 앱 스토어에 공개 배포하지 않고, 관리자가 초대한 사람에게만 테스트 배포로 제공합니다. 광고, 분석 도구, 추적 기능은 없습니다.

서버에 저장하는 정보

  • 프로필: 표시 이름, 관리자 여부, 학습 설정(학습할 언어 트랙, 하루 목표, 시간대, 음독 표기, 테마, 효과음)
  • 학습 기록: 문항별 정답·오답·건너뜀, 답하는 데 걸린 시간, 답한 시각, 복습 일정
  • 학습 결과: 세션 요약과 XP, 수준 진단 결과, 단원 시험 결과
  • 선택 사항인 4자리 PIN과 관리자 복구 코드: 원래 값이 아니라 복원할 수 없는 해시만 저장합니다.

이 정보는 학습 일정을 계산하고 기록을 보여 주는 데만 쓰며, 판매하거나 다른 목적으로 제공하지 않습니다.

저장하지 않는 정보

이메일, 전화번호, 생년월일, 위치, 연락처, 광고 식별자, 기기 식별자를 받지 않습니다. 앱 데이터베이스에 IP 주소를 기록하지 않습니다.

  • 인터넷이 끊겼을 때 서버로 아직 보내지 못한 학습 기록
  • 로그인 상태를 유지하는 서명된 세션 값(최대 2시간 유효)
  • 서버에 아직 저장되지 않은 설정 변경

앱을 삭제하면 이 정보도 함께 삭제됩니다.

마이크

발음 연습 화면에서 녹음 버튼을 누를 때만 마이크 권한을 요청합니다. 녹음은 최대 15초이며 기기 메모리에서 다시 듣는 데만 쓰고, 서버로 보내거나 저장하지 않습니다.

서비스 제공 업체

앱 서버와 데이터베이스, 발음 음성 파일은 Cloudflare에서 운영합니다. Cloudflare는 요청을 전달하는 과정에서 IP 주소 같은 접속 정보를 처리할 수 있습니다. 발음 음성은 미리 만들어 둔 파일이며 사용자 정보를 담지 않습니다. 글꼴은 앱에 포함되어 있어 외부 글꼴 서비스에 접속하지 않습니다. 서버 오류가 나면 오류 내용이 문제 해결을 위해 일시적으로 기록될 수 있습니다.

삭제

관리자는 설정 화면에서 다른 프로필을 영구 삭제할 수 있으며, 이때 그 프로필의 학습 기록과 결과도 모두 삭제됩니다. 관리자 프로필 삭제나 전체 데이터 삭제는 앱을 공유한 관리자에게 요청해 주세요.
