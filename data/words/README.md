# Korean word seed license

`kr-wiktionary.json` is derived from the immutable Korean Wiktionary revisions
linked in each row and in `data/SOURCES.md`. It is distributed under the
[Creative Commons Attribution-ShareAlike 4.0 International license](https://creativecommons.org/licenses/by-sa/4.0/).

The file retains only each selected entry's exact two-character Hanja spelling
and Hangul page title. No definition or example prose is copied.
