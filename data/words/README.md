# Word seed license

The word files are derived from immutable Korean, Japanese, and Chinese
Wiktionary revisions linked in each row and in `data/SOURCES.md`. They are distributed under the
[Creative Commons Attribution-ShareAlike 4.0 International license](https://creativecommons.org/licenses/by-sa/4.0/).

The files retain only each selected entry's exact two-character spelling and
reading. No definition or example prose is copied.
