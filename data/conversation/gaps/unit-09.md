# Unit 9 gaps (좋아하는 것·경험·의견)

Wanted by the curriculum, no suitable Tatoeba sentence (CC BY 2.0 FR / CC0). Not invented. Searched 2026-10-06.

- 食べたことがあります (polite, no object, learner side): no hit. Shipped 見たことがあります。 (#2374996) as a generic "yes, I have" and 私は食べたことがありません。 (#6137181) for "no". The food questions found are object-specific (海苔, 鉄板焼き, バナナパイ); only 日本の食べ物を食べたことがありますか。 (#1168408) is generic enough, and it is not used in a scene.
- 行ったことがあります + 感想 in one line (e.g. 去年京都に行ったことがあります。とても良かったです): no hit. The scene joins two separate sentences.
- どうでした？ as a bare casual question: no hit. Only travel-specific forms exist (旅行どうでした？ #4751196, 旅行はどうでした？ #4751200); どうでした、旅行は？ (#4751197) is shipped as the casual variant.
- 〜と思います with a topic marker the learner can reuse ("日本料理はおいしいと思います" and similar): no clean hit. おいしいと思います only occurs inside a longer recommendation (#1213093). Shipped 綺麗だと思います。 (#10952563), 私もそう思います。, そうは思いません。.
- けっこう〜 (polite, adjective): no hit. 結構面白い。 (#175785) is casual only; 私は結構お酒に強いんです。 (#157332) was not shipped (odd topic for a learner).
- まあまあです (bare, polite): only カレーはまあまあでした。 (#76792, topic-specific). 「調子どんな？」「まあまあ」 (#10616349) is a quoted dialogue and 彼の英語はまあまあだ。 (#118104) is third-person; both rejected.
- 私も好きです / 私もです (agreeing to a stated like): no standalone sentence. 私もです exists only inside quoted dialogues (#236293, #2112264). Substituted 私もそう思います。 (#4002020) for opinions.
- あまり好きではありません with the casual or soft form (あまり好きじゃないです): all hits are a named person's view (#8649619, #2948368) or plain-form. Shipped ビールはあまり好きではありません。 (#2137193) only.
- おすすめです / 〜はおすすめですよ (recommend after an experience): no first-person hit. Found only questions (おすすめは何ですか。 #227687) and a travel suggestion (電車で行くのをおすすめします。 #1689582), neither used.
- 食べ物の感想 as a question from the other side (お料理はどうでしたか): no clean hit. The only match is a quoted dialogue (「料理はお口に合いましたか？」#11270013). 宿泊先はどうでしたか？ (#12754558) is shipped as hear but is not used in a scene.
