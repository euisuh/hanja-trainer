# Unit 13 gaps (문제 해결·병원·약국)

Wanted by the curriculum, no suitable Tatoeba sentence (CC BY 2.0 FR / CC0). Not invented. Searched 2026-10-06.

- 〜が壊れてるみたいで: no polite hit. Hits are casual (鍵が壊れてるんだよ #10659496, 洗濯機が壊れてるんだ #11364982, これ、壊れてるよ #9179929) or plain (この時計は壊れている #221604). Not shipped; substituted お湯が出ません。 (#226801) and これは注文と違います。 (#2255796).
- 〜を落としちゃって (polite, to staff): only casual 落としちゃった / なくしちゃった (#9725544, #11733057) and third-person sentences. Substituted すみません、お箸を落としてしまったんですが。 (#2233267) and 昨日、鍵をなくしてしまいました。 (#10899609).
- 財布をなくしてしまったんですが / 携帯を落としてしまいました: no hit. 財布をなくしました only as a commute-specific line (通学中に財布をなくしました。 #11512516), not shipped. イヤリングを片方失くしたんです。 (#2097872) is object-specific; learner swaps the noun.
- どうすればいいですか (to staff): hits are all 〜するにはどうすればいいですか with a task attached; plain どうしたらいい is casual (#3366793). Shipped 払い戻しはどうしたらいいのですか。 (#83847), refund-specific.
- いつからですか answers (昨日からです / 二、三日前からです): no polite learner-side hit. Only 昨日から脛が痛い。 (#10621272, plain, shin-specific). So 痛みはいつからですか？ (#9859016) ships as a `hear` chunk but no scene can answer it; scene 1 skips it.
- 〜はありますか with a medical noun: 頭痛薬 (#123865), 頭痛に効く薬 (#123816), 風邪に効く薬 (#83973) shipped. No polite 胃薬 / 目薬 / 湿布 / 絆創膏 sentence.
- 保険証 / 問診票 (staff asking for a card or form): 保険証 only in 毎月初めは保険証を提示してください。 (#10963743, rule statement); 問診票 only in a long clause (#4489072). Substituted こちらの書類にご記入ください。 (#2903638) and こちらに氏名・住所・電話番号をご記入ください。 (#8866543).
- どうされました？ (short form): no standalone. 今日はどうされましたか。 (#10588666) shipped; the longer 「今日は、どうされましたか？」… (#10889358) is a multi-speaker excerpt, not used.
- Learner answers to staff questions (はい、初めてです / 熱は三十八度です / アレルギーはありません / 食物アレルギーはありません): no polite hit, so アレルギー, 初めての診察, 飲んでいる薬 questions ship as `hear` only, with no scene reply.
- 熱を測りましょう / 食後に飲んでください (staff dosage instructions): only imperative 食後にこの薬を服用しなさい。 (#145874, stern) and 一日三回飲みなさい (#226390); rejected. Substituted いたいときは、いたみどめをのんでください (#11243057).
- Wrong-order staff replies (すぐお取り替えします / 作り直します): no hit. Scene for a wrong order is not built; only the learner lines (#2255796, #218300) ship, with 申し訳ございません。 (#1483682) on the `hear` side.
- 保険証 for travelers / 旅行保険 questions (#11234997, #11264781) exist but are insurance-company talk, not clinic intake; not used.
- Unit has no wrong-order scene because the staff side of the exchange (replacement offer) is a gap. Scene 2 covers the lost-item case instead.
